## 一、提交前必跑的 6 条命令

在仓库根目录依次执行，**每条都要看到期望结果**：

| # | 命令 | 期望输出 | 不通过怎么办 |
| --- | --- | --- | --- |
| 1 | `python scripts/check.py` | `[PASS] check 全部通过`，末行 `NN passed` | 看 `[FAIL]` 是哪个环节：契约 / 配置 / 单测 / 端到端 / 纵切 |
| 2 | `python scripts/run_golden.py` | 5 行 `[OK]`，退出码 0 | 某个 `[FAIL]` 会直接写明"期望 X，实际 Y" |
| 3 | `python scripts/package_release.py` | `[OK] 打包 N 个文件` + `[OK] 解压后 check.py 通过` | **解压验证失败 = 不许交付**，脚本会自动删包 |
| 4 | `python scripts/collect_evidence.py` | 打印四节数字 + `已写入 outputs/证据汇总.md` | 任一节报错说明对应模块挂了 |
| 5 | `python scripts/verify_http.py` | `[PASS] 真实 HTTP 三接口通过` | 需要 **`fastapi` + `httpx` + `uvicorn`**（httpx 最常漏）；未装先 `pip install fastapi httpx uvicorn` |
| 6 | `python scripts/count_intro.py` | `A 版字数：NNN / 300 → OK` | 超限就删字，**不要压到 299**（口径差异会判超） |
| 7 | `python scripts/check_video.py <视频>` | `[PASS] 参数合格`（时长 5–8 分钟 / ≥1080p / h264 或 hevc / ≤500MB）；**无音轨只记 WARN**（赛题要求字幕烧录，字幕横条同样承载讲解） | 需要 `ffprobe`；参数不合格会逐条列出原因 |

> 1–4 条不依赖网络；5 条只起本地端口；6–7 条纯本地计算。**全程不需要 API Key。**
>
> **前置条件**：
> - 第 3 条**在 git clone 内执行**最稳妥（脚本已支持无 `.git` 快照，但 `MANIFEST.txt` 的 commit 需要 `GIT_COMMIT` 环境变量注入，否则记 `unknown`）；
> - 第 5 条需要 **fastapi + httpx + uvicorn 三个包**（只装 fastapi/uvicorn 会因缺 httpx 失败）：
>   `python -m pip install fastapi httpx uvicorn`

## 二·五、成片材料放哪（不进仓库）

视频、PPT、PDF 成片**不入库**——体积大、且它们是交付包内容而非源码。

| 材料 | 放哪 | 为什么不入库 |
| --- | --- | --- |
| 演示视频 mp4 | 仓库外目录（如 `D:\未来杯-ChainGuard\成片材料-<日期>\`） | 十几 MB 起，且赛事要求打包上传 |
| PPT / PDF | 同上 | 二进制成片，仓库里只保留生成用的 markdown |

**踩过的坑**：成片目录若放在仓库内（哪怕写了 `.gitignore`），
`check_contracts.py` 的「归属覆盖」仍会因为它是个新的一级目录而报错——
归属检查扫的是工作区，不是 git 索引。所以成片必须在仓库外。

## 三、红线检查（必须逐条确认"否"）

- [ ] 仓库是否仍是 **private**？（`gh repo view --json visibility`）
- [ ] 是否**没有**开启 GitHub Pages？
- [ ] 提交包里是否**没有**任何 API Key、token、`.env`？
- [ ] 是否**没有**校名、导师姓名、学号？
- [ ] 是否**没有**第三方 PDF 原件、论文图表？（`knowledge/corpus/` 只应有 `.md`）
- [ ] 是否**没有**把语料包传到公开仓库/网盘？（著作权法第二十四条第六项）
- [ ] 材料里的"已实现"是否都能在 main 上找到对应代码？（分支内结论不算）

> 最后一条最容易踩：**分支上做完不等于 main 上有**。验收一律以 `git rev-parse origin/main` 为准。

## 四、常见故障与处置

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| `check.py` 报「归属覆盖：某目录未登记」 | 新增了一级目录 | 在 `docs/owners.yaml` 补 owner/backup |
| `check.py` 报「契约正反例不符」 | 改了 schema 没同步 examples | 同步 `contracts/examples/*.good/bad.json` |
| 打包解压后 `check` 失败 | 白名单漏了新目录 | 改 `scripts/package_release.py` 的 `INCLUDE_DIRS`；新增的 `tests/test_package_snapshot.py` 会直接点名漏了哪些文件 |
| `verify_http.py` 起不来 | 缺 fastapi / httpx / uvicorn（**httpx 最常漏**） | `pip install fastapi httpx uvicorn` |
| 示例包 `commit_sha` 与 main 不符 | 用旧提交生成的 | **用当前 main 重新生成**，不要手改 manifest |
| `git push` 直连超时 | 本机网络策略 | 走代理：`git -c http.proxy=http://127.0.0.1:7897 ... push` |

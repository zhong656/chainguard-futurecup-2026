## A 版（投稿版，≤300 字）

**链衡 ChainGuard** 是多智能体编排与可核验交付平台。

知识库把语料做成可溯源转述卡，混合检索召回率 100%；6 类角色以 YAML 声明，改配置即生效；工作流用 DAG 编排 11 个节点；调度器提供并发、超时重试与失败降级；评分未达阈值时，Self-Loop **定位到段落**并只重跑相关节点；验证分两层——L1 确定性规则与 L2 温度不同的独立评审，任一 blocker 一票否决；失败样本入库并支持前后对比。

FastAPI 与 Docker 一键启动。每次运行产出 9 件交付物，全部进 manifest 并带 sha256，证据可回到原文逐字核对。Mock 模式零 Key 可复现，260+ 项测试与故障注入通过。

## B 版（完整版，供项目书 / PPT）

**一句话定位**：不是聊天机器人，而是**把多智能体的产出变成可核验交付物**的编排平台。

### 六项能力

| # | 能力 | 实现 |
| --- | --- | --- |
| 1 | 知识库定义与集成 | 17 份语料按声明式清单入库，切片为可溯源转述卡；BM25 + 向量混合检索，RRF 融合 |
| 2 | Agent 团队定义 | 6 类角色（planner / researcher / analyst / writer / verifier / reviewer）全部 YAML 声明，含工具白名单、I/O 契约、模型档位；改配置不重启生效 |
| 3 | 工作流编排 | DAG 编译 11 个节点，支持条件分支、并行 fanout、循环边与定向回退 |
| 4 | 动态调度 | 并发信号量、单节点超时、指数退避重试、失败降级、Token 预算护栏；故障注入可复现 |
| 5 | Self-Loop | 评分未达 0.85 时生成**定位到段落**的修订指令，只回退到指定前驱节点重跑，最多 3 轮 |
| 6 | 结果验证与反馈 | L1 规则（引用 / 数值 / 章节 / Schema）+ L2 独立评审（温度与撰写者不同，相同则拒绝启动）+ 一票否决；失败样本入库，统计与前后对比 |

### 可核验交付（本项目的差异点）

每次运行产出 9 件文件，全部登记进 `manifest` 并附 sha256：

```
solution.md            正文
evidence_chain.json    引用了哪些文档
evidence_refs.json     每条引用的 文件 / 页码 / 字符区间 / 原文 / 哈希
                       （页码仅分页格式才有值，Markdown 语料为 null）
scorecard.json         评分卡
rounds.json            每轮评分（fail→pass 的物证）
charts/*.svg           评分卡五维 + 收敛曲线
trace.jsonl            全链路事件
delivery_artifact.json 交付清单
```

**别人给的是结论，我们给的是可回到原文逐字核对的证据。**

### 实测数据

| 指标 | 结果 |
| --- | --- |
| 测试 | 261 passed（契约 9 项 + 单测 + 端到端 + 纵切 + HTTP + 容器） |

| Self-Loop | R0 0.95 **fail**（1 条 blocker）→ R1 1.0 pass |
| 故障注入 | `fail`×3 / `retry`×2 / `degrade`×7，降级后安全中止并保留 trace |
| 复现 | Mock 模式零 Key，`python -m src.run` 30 秒出包 |

### 边界声明（如实）

- **L3 双路检索比对尚未实现**：配置为 `false`，设为 `true` 会拒绝启动，不会静默忽略；
- **L2 在 Mock 模式下是启发式判定**，接真实模型走同一接口；
- 语料为**原创转述卡**，不含第三方作品原文，许可与署名见 `docs/语料来源与合规.md`。

> 说明这些不是减分项：**能说清边界，比宣称"全都做了"更经得起追问。**

# 语料来源与合规说明

> 本文件是 `knowledge/` 下 17 份语料的**合规依据汇总**，与 `knowledge/ATTRIBUTION.md`（署名要求）、
> `knowledge/sources.yaml`（逐条登记）配套使用。
> 完整判定见原始材料《语料合规说明.md》（由语料整理者编写，逐份核到权利人条款）。
>
> **一句话结论**：语料包内**不含任何第三方作品原文**，全部为本团队原创转述卡；
> 使用的是不受著作权保护的事实、数值、法条与官方元数据，并逐条标注出处。

## 一、法律依据

《中华人民共和国著作权法》（2020 年第三次修正）：
[gov.cn 官方全文](https://www.gov.cn/guoqing/2021-10/29/content_5647633.htm)

- **第五条**：本法不适用于法律、法规、国家机关的决议/决定/命令等具有立法、行政、司法性质的文件，
  以及**单纯事实消息**、通用数表与公式。
  → 本包的**法律条文**（数据安全法、个人信息保护法）、**行政规范性文件**（工业数据分级指南、
  十四五智能制造规划、国家标准公开办事指南）、**统计数值**、**标准元数据**、**分辨率计算式**均落入此条。
- **第二十四条**：为介绍评论、科学研究而适当引用可不经许可，但须指明作者与作品名称，
  且其中第（六）项明确「**不得出版发行**」。
  → 这划出了边界：**私有仓库、非公开评审可以；公开发布全文不行**。

## 二、逐类处置

| 类别 | 份数 | 权利状态 | 本包做法 |
| --- | --- | --- | --- |
| 法律 / 行政法规 | 3 | 不受著作权保护（第五条一） | 转述要点 + 条款指引 |
| 标准元数据（GB/T） | 2 | 标准全文受保护；**号、名、状态、日期、分类号**属事实（第五条二三） | 只取元数据，禁止复制条文 |
| 统计 / 规划 | 3 | 事实数值不受保护；**网页版式**受保护 | 转述 + 显著署名 |
| 开放获取论文（CC BY 4.0） | 2 | 可复用，须署名；**综述内第三方图表不再授权** | 不收录 PDF 原文与图表 |
| 厂商 / 机构文档 | 4 | 未见内容再分发授权 | 仅事实性转述，不复刻正文 |
| 办事指南 | 1 | 行政性质文件 | 转述 |

## 三、具体做了什么

1. 13 份网页类语料**删除了「页面正文（摘录）」整段**，改写为原创中文转述；导航、页脚、版权声明等版式内容不入库。
2. 4 份 PDF 原件（A5 / A6 / B1 / C1）移出语料目录，存放于项目外，**不随包分发**。
3. `sources.yaml` 每条带 `legal_basis` / `redistribution` / `attribution` / `third_party_text_included: false`，
   许可判定以字段为准，不靠记忆。
4. 代码层面：`src/knowledge_hub.py` 切片时**跳过 YAML front-matter 与「三、权利依据」之后的合规声明段**，
   避免"版权/署名"类查询命中样板文字（片段数由 119 降到 51）。

## 四、能做什么 / 不能做什么

| 场景 | 结论 |
| --- | --- |
| 四人私有仓库、本地检索与切片 | ✅ |
| 作为参赛作品压缩包提交组委会、非公开评审 | ✅（须附 `knowledge/ATTRIBUTION.md`） |
| 项目书、PPT、答辩中引用事实并标出处 | ✅ |
| 演示视频展示出处清单与追溯链 | ✅ |
| **上传到公开 GitHub / 网盘 / 镜像** | ❌（第二十四条(六)「不得出版发行」） |
| 随作品附带第三方 PDF 全文或论文图表 | ❌（已隔离） |
| 用于广告、招商、商业宣传 | ❌ |
| 去掉署名、把转述说成自有技术成果 | ❌（署名权不可放弃） |

## 五、明确排除的材料

## 六、诚实声明

这是一份**基于已核实公开条款做的合规工程设计，不是法律意见**，任何人都不能替权利人给出"绝对零风险"的保证。
本方案做的是：把所有第三方受保护表达从交付物中移除，只保留不受保护的事实与本团队原创文字，并逐份留下出处与署名。
若学校或组委会另有材料要求，请指导老师据此再确认一次。

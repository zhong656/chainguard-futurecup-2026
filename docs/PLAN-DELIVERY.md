## 四、三条必须守住的规矩

1. **格式先行。** 每个人只依赖 `contracts/` + mock，不依赖"谁写完了"。B 的检索没写完，D 用 mock 结果照样能编排出图；C 的验证器没好，D 用假评分卡照样能调回退。**谁等谁，就说明格式没定好。**
2. **纵切是最大风险点。** 11/07 之前必须见到"一条命令跑完全链路"。见不到就当天降级：砍前端 → 砍真实模型 → 砍 A/B 对比，**保住 Mock 全链路 + 规则验证器 + 一次定向回退**。别死磕到 11/17。
3. **11/16 之后不再收新功能。** 之后只修"阻碍复现和材料一致性"的问题。任何"再优化一下"的想法，记进 `decisions.md` 的待定，赛后再说。

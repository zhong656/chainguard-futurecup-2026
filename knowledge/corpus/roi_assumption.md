## 测算结构

```
年化收益 = 复检人力节省 + 客诉赔付减少 + 良率提升收益
年化成本 = 一次性投入 / 折旧年限 + 年运维费
回收期(月) = 一次性投入 / (月均收益 - 月均运维)
```

## 关键假设（需逐条可追溯）

| 假设 | 示例值 | 追溯要求 |
| --- | --- | --- |
| 复检人数 | 3 人/班 | 必须来自企业实际或明确标注为示例 |
| 人均年成本 | 12 万元 | 同上 |
| 客诉赔付下降 | 30% | 需历史数据支撑 |
| 折旧年限 | 5 年 | 会计口径，可引用通用规定 |

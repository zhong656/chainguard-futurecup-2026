## 一、可核验事实（不受著作权保护）

- KubeEdge 是把 Kubernetes 容器编排与设备管理扩展到边缘侧的开源系统
- 架构分云端与边缘端：CloudHub / EdgeController / DeviceController 与 Edged / EdgeHub / MetaManager / EventBus / ServiceBus / DeviceTwin
- 边缘侧可在本地处理数据，减少上行带宽并提高响应速度
- 页脚版权：All rights reserved
